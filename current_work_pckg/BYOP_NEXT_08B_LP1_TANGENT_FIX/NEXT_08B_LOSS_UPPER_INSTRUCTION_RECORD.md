# NEXT-08b LP1 loss-upper fix: researcher instruction (verbatim, 2026-10-23, chat)

同意按照方案 A，继续准备 NEXT-08b 的 LP1 损耗上界修复，但暂不授权新的优化器调用。
PTDF 诊断已经明确指出 LP1 的 Line-loss_upper 被设置得过高，允许使用非物理损耗改变潮流和线路扩容决策。请针对这一问题完成最小修复。
特别注意：不能简单删除 apply_reference_tangents() 中的 Line-loss_upper 缩放语句。因为 LP1 的 s_nom 仍然是优化变量，而损耗切线在 S_ref 处固定；若同时固定 loss_upper = r·(0.7·S_ref)²，数学上会强制 |Line-s| ≤ 0.7·S_ref，即使 s_nom 扩大也无法进一步提高可传输潮流。
请优先研究仍保持 LP 的容量相关损耗上界，使其在 s_nom = S_ref 时与 LP2 完全一致，而在 s_nom 变化时不会引入上述隐性潮流限制。可考察在 S_ref 处对二次损耗上界进行仿射线性化，但必须处理参考容量以下的非负性和可行性问题。
提交求解审批前，必须完成：

1. 使用解析公式和小网络测试证明，新约束不会使线路扩容失效，也不会允许恢复之前 GW 级的人工损耗。
2. 使用真实网络完成零求解器模型构建，核对全部 Line-loss_upper、Line-loss_tangents、Line-ext-s_nom-upper 和线路额定容量约束。
3. 在固定点 S_ref = s_nom 时，验证 LP1 与 LP2 的损耗约束一致。
4. 在 s_nom 高于和低于 S_ref 的代表性情况下，检查损耗上下界是否可行、是否引入意外容量下限或其他新的可行域错误。
5. 保留原有 G1–G3、容量—电阻迭代规则、LP2 可靠性验收标准，不修改 S0–S3。
6. 继续使用独立目录、manifest、审批 SHA 和求解台账，保留所有此前结果。

完成静态测试后再申请最多 3 次 LP 求解，零重试。不要自动重跑，更不要通过放宽 83.7 MW 最大缺供阈值来通过验收。
目标是在解决已经确认的 LP1 可行域错误后，尽快完成最后一次有损基准校准，进入正式 S0/S1 和 S2/S3 主线。
