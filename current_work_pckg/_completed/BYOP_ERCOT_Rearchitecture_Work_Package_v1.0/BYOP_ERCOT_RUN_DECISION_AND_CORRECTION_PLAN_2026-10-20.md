不得直接依据本轮结果声称：

- 某个场址的 S1 延迟就是物理电网能够实现的最短并网延迟。
- 当前 S2 的 BYOP 投资选择就是严格 Speed-First 的最优决策。

- BYOP 已经导致 2040–2050 年公共投资路径依赖、重复建设或搁浅资产。

尤其需要注意：

**当前新架构主要运行 2026–2031 年静态多期 LP，尚未完成 2026–2050 年的年度不可逆投资决策模拟。**

因此，目前无法验证论文最重要的长期机制 M3。

## 3. 下一轮必须修正的 P0 问题

### P0-1：已投运数据中心容量不应在下一年度自动消失

#### 已发现的问题

当前 S1 计算结果中，ABI_TAY 的 IT 服务容量出现：

| 情景 | 2027 | 2028 | 2029 |
|---|---:|---:|---:|
| G-K | 250 MW | 0 MW | 868 MW |
| G-U | 86 MW | 0 MW | 868 MW |

现有模型将每年的 IT 服务容量作为相互独立的优化变量，没有充分表达已经投运的 IT 容量在下一年继续存在的物理事实。

这一设定会影响：

- 数据中心 COD 判断；
- 最早可交付容量；
- BYOP 需求和投资选择；
- 年度延期损失；
- S2 与 S3 服务轨迹；
- 后续资产利用和路径依赖。

#### 要求的修正

明确区分以下变量：

1. `IT_online[s,y]`：累计已投运的 IT 容量。
2. `IT_add[s,y]`：当年新增投运容量。
3. `IT_served[s,y]`：当年获得实际供电服务的 IT 容量或相应服务指标。
4. `IT_unserved[s,y]`：尚未交付或无法满足的 IT 需求。
5. 运行期间的实际可中断负荷与训练灵活性。

在没有明确退役、退出或项目取消的情况下：

\[
IT^{online}_{s,y}\geq IT^{online}_{s,y-1}
\]

同时，必须允许实际负荷在 Conditional Firm 或其他灵活运行条件下发生中断。

**不能把运行负荷削减错误地表示为已投运 IT 资产被撤销。**

#### 验收要求

- 无退出项目的累计投运容量不能逐年下降。
- 投运状态和实际服务量有清晰区别。
- 相关约束在 S1、S2、S3 中一致。
- 不引入整数变量，保持 LP。
- 增加对应单元测试和跨年服务轨迹检查。

### P0-2：S1 经济最优供电不等于物理最早可交付供电

#### 已发现的问题

当前 ABI_TAY 在 2027 年：

- G-K 的 S1 服务量约为 250 MW；
- G-U 的 S1 服务量约为 86 MW。

G-U 增加了未来输电扩张选择，但 2027 年服务量反而较少。

这并不一定是物理可送达性下降。

更可能的解释是：当前 S1 仍使用有限的计算服务价值参数，与公共投资及运行成本进行跨年经济权衡。

因此，求得的 S1 服务量可能是经济最优供电量，而不是最早物理可行供电量。

#### 对 S2 的潜在影响

目前 `s1_offer()` 使用 S1 最优解中的实际 Firm POI 潮流，作为开发商事前获得的电网供电上限。

这可能产生以下错误传导：

**S1 因经济原因少供电 → 模型误认为电网缺少物理可交付能力 → S2 选择更多 BYOP → 对 Speed Premium 和社会效率的估计发生偏差。**

这个问题直接涉及论文核心研究机制，必须优先解决。

#### 要求的修正

建议保留当前经济最优 S1，作为一个对照结果。

与此同时，单独构建物理最早可交付的 Grid-Only 基准，例如：

`S1_GRID_EARLIEST`

采用与 S2 Speed-First 相一致的两阶段原则：

**第一阶段：** 在实际 POI 设备、输电、资源充裕度、程序审批和建设周期约束下，逐年严格优先最大化能够持续投运的数据中心容量。

**第二阶段：** 在第一阶段确定的最早交付服务轨迹下，最小化公共电力系统资源成本。

据此区分：

- 物理最早可交付容量；
- 经济最优实际服务容量；
- 经模型假设或实际资料支持的 Firm/Conditional Firm 供电资格。

企业 S2 决策中可获得的电网容量，需要有明确的物理可行性或供电资格依据。

不能直接把 S1 的经济最优供电量视为电网的物理供电上限。

#### 验收要求

1. 多场址公共供电容量不能被重复分配。
2. 相同背景负荷和可靠性条件下，仅增加可行扩建选项，不应降低严格 Speed-First 的最早可交付容量。
3. S2 使用的供电资格能够追溯到可行性约束。
4. 修正后的 S1/S2/S3 必须重新求解，不能仅对既有结果进行数值修补。
5. 严格 Speed-First 的具体定义及其数学实现须在修复报告中说明。

## 6. 重新开展长期模拟的门槛

当前研究的核心不只是 BYOP 能否缩短数据中心接电时间，而是其对公共电力系统长期投资的影响。

因此，在以下条件满足之前，不建议启动大量 2050 年计算：

1. S1 最早物理可交付服务得到合理定义和验证。
2. S2 Speed-First 企业决策能够使用可信的电网可交付容量。
3. S2 资产和电网服务权利可以传递给后续公共规划。
4. 已经投运或承诺建设的公共和私人资产能够跨年度延续。
5. 建设周期、COD、退役、项目退出和资产再利用得到一致处理。
6. S2 与 S3 在相同服务水平下能够比较社会真实资源成本。

完成以上事项后，优先研究：

- M2：BYOP 对公共发电、储能和输电扩张的影响；
- M3：2026–2035 年投资行为形成的 2036–2050 年资产锁定、冗余或再利用；
- M4：企业私人成本最小化与社会协调规划之间的差异。

这些是后续论文工作的主要研究目标。

**本阶段核心原则：保留已经计算的诊断信息，修正决定科学结论的关键逻辑，然后再投入资源研究 BYOP 的公共扩张反馈和长期路径依赖。**
