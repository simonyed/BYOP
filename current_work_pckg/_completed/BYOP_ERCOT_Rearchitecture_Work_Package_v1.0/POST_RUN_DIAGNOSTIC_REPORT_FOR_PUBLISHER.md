S1 延迟归因（R1，逐项放松后增加的服务量，单位 MW_IT·年）：
- **PEC**：2,750 全部来自 POI 设备（场址无接入设备，升级需 5 年）。
- **DFW**：1,403 全部来自 POI 设备，其中与审批程序重叠 173。
- **ABI**：G-W 中 132 来自设备（2029 年 1,000 MW 设备只够约 868 MW IT）。G-K 中 2028 年那 500 单独放松上游输电或系统充裕度都能消除，两者互为替代（交互项为 −500）。

结论：**纯电网延迟主要由 POI 设备和审批工期这两个外生假设决定**，网络的内生约束只在加入竞争负荷后的 ABI 2028 年起作用。

## 6. 对研究者六个问题的回答

1. **ERCOT 输电骨干 → POI → S2 企业决策 → 公共电网优化是否已实现端到端运行？**
   **Yes（技术上）。** 三种设置都跑完了完整链条：S0、S1、S2（企业阶段四种模式 + 公共阶段一致性检验）、S3 和匹配服务比较，全部是最优的纯 LP。
2. **当前 S1、S2、S3 结果中，哪些满足物理和经济解释要求？**
   **部分满足。**
   - 满足：DFW 和 PEC 的 S1 延迟可以追溯到有出处的设备和审批工期；S2 的 BYOP 选择符合工期逻辑（SOFC 0.5 年、RICE 2 年）；S2 的公共阶段一致；两项零值和禁用对照通过。
   - 不满足：ABI 的服务量下降（P0-1）；S1 是经济最优而不是物理最早（P0-2）；S0 有切负荷（I-4）；数据中心挤占背景负荷（I-5）。
3. **P0-1、P0-2 可能怎样影响主要结论？**
   - P0-1 会改变 ABI 在 G-K/G-U 中的 S1 轨迹：服务量不再下降，要么推迟投运，要么部分时段中断。
   - P0-2 会把企业报价改为物理最早可交付量：ABI 的 BYOP 规模可能下降。DFW 和 PEC 的延迟来自设备和审批，预计仍会选择 BYOP。
   - 修正 I-5 后，S2−S3 的匹配服务差额中来自切负荷的部分会显著变化。
   - **因此 M2/M4 的数值都需要重算**，方向性信号（BYOP 替代公共投资、存在冗余资产）需要在修正后重新确认。
4. **下一轮修复需要修改哪些文件、预计多少计算时间？**
   - 文件：`rearch_mech.py`、`v240_mech.py`、`collect_rearch.py`、新的单元测试、`run_rearch.sh`，以及 `inputs/grid` 下的 TPIT 台账和基准资产。**以上已全部完成**（见第 9 节）。
   - 计算时间：小算例约 1–2 小时；正式 R2 三个设置并行约 6–10 小时，其中 S1_EARLIEST 的分层求解约为单次求解的 2–4 倍。
5. **修复后的最小 ERCOT 算例应满足哪些验收条件？**
   见 `P0_MODEL_CORRECTION_PROPOSAL.md` 第 5 节和研究者 P0 决策第 4 节 Step 5：纯 LP；投运容量不下降；中断损失与服务价值一致；非计划中断不超过 0.5%；新增 AIDC 不增加既有用户切负荷；多场址不重复获得容量；不合格场址不锁死 max-min；S1_EARLIEST ≥ S1_ECON（同一可行域）；S2_off = S1_ECON；S1_zero = S0。
6. **当前是否具备启动 2026–2050 年长期路径依赖研究的条件？**
   **No。** 研究者计划第 6 节的前提（物理最早交付已验证、企业使用可信的电网可交付量、资产与权利的跨年传递、退役与复用的一致处理）尚未全部满足，`v240_path` 年度控制器也还没有接入新架构。
