# BYOP 研究整体框架：从企业追求快速供电，到电力系统长期路径依赖

我已阅读最新 BYOP LP-Core v2.2.9 的总控文档、核心配置和 WP0–WP7 工作包。

从顶层设计看，这项研究的目标不是精确预测美国未来将建设多少数据中心和发电机组，而是通过一个具有真实空间、技术和投资约束的电力系统模型，识别：

数据中心为追求 Speed-to-Power 而自主建设或取得电源，如何改变公共电网的扩张路径？在什么条件下，这种行为能够提高系统效率，又在什么条件下造成重复投资、资产锁定和长期社会成本？

这是论文准备向 Nature Energy 论证的核心科学问题。

## 一、研究的总体逻辑

AI 数据中心需求快速增长（2026–2035）

全国 Low / Mid / High IT 增量，分配到美国各州及电网区域

公共电网接入能力和新电源建设存在时滞

已有容量、输电瓶颈、POI 约束、未来扩建速度

数据中心开发商选择供电方案

等待电网 / 签订供电合同 / 复用资产 / 自建电源

短期影响

提前投运、投资成本、并网容量占用

长期反馈

公共投资调整、资产利用、搁浅与再利用

比较企业自主投资与社会协调规划

私人收益与系统真实成本是否一致？差异由什么机制驱动？

寻找机制成立的条件、临界点与政策含义

不是预先证明 BYOP 一定好或一定坏

整个研究可以理解为三个层次：供电方案的形成、方案对系统扩张的反馈、长期成本及效率的评价。

## 二、通过四个主情景建立反事实比较

这是整篇论文最重要的实验设计。

| 情景                         | 含义                               | 研究用途                              |
| -------------------------- | -------------------------------- | --------------------------------- |
| S0 — No New AIDC           | 保留已有数据中心和公共负荷，不增加本研究的新数据中心需求     | 建立没有新增 AIDC 的公共电网扩张基准             |
| S1 — Grid-Only             | 新数据中心依赖公共电网，并可因接入能力不足而等待投运       | 衡量新增 AIDC 对电网建设与供电等待的影响           |
| S2 — Developer-Driven BYOP | 数据中心按照自身经济利益，选择等待、合同、自建或复用电源     | 衡量 Speed-to-Power 激励如何改变私人投资及电网扩张 |
| S3 — Coordinated Planning  | 数据中心和电力系统在共同物理约束下，按照社会真实资源成本协调规划 | 衡量自主投资相对于协调规划的效率差异                |

这四个情景构成三个主要对比：

S1 − S0

数据中心增长的影响

在没有 BYOP 的情况下，新增需求如何推动公共电网扩张？

S2 − S1

开发商自主 BYOP 的影响

BYOP 能提前多少供电，又如何替代或增加公共投资？

S2 − S3

自主决策与社会协调之间的效率差异

私人追求更快投运，是否导致社会资源配置偏离协调方案？

这里需要特别注意：S2 和 S3 使用相同的信息、技术条件、建设周期和物理约束，区别主要是决策目标与成本承担方式。否则，无法将结果差异归因于企业与电网之间的决策协调机制。

此外，由于不同情景可能交付不同数量的数据中心服务，工作包还要求同时报告实际交付结果，以及控制服务量后的 matched-service comparison，避免把少供电造成的低成本误认为更高效率。

## 三、S2 中数据中心开发商如何作出决策？

S2 是整个研究的核心。

我们并不预先规定数据中心必须自建多少电源，而是让开发商根据建设速度、投资成本、合同价格和可获得的公共电网供电能力，自主选择。

### 1. 三种供电模式

| 供电模式                    | 特点                                                 |
| ----------------------- | -------------------------------------------------- |
| Grid-Only               | 完全依赖公共电网供电，可能需要等待电网扩建                              |
| Grid-Connected Flexible | 同时利用公共电网与自有、合同或其他合格电源，可选择 Firm/Conditional Firm 服务 |
| Islanded                | 不依赖公共电网进口，需要依靠自身可交付的供电资源                           |

与此同时，区分三种电源取得路径：N（新建电源）、R（复用既有或退役资产）、C（取得合格供电合同）。两者相互独立，不应混淆。

例如，Grid-Connected Flexible 既可以采用自建燃气机组，也可以复用既有机组或购买合格容量合同。

### 2. Speed-to-Power 如何影响技术选择？

开发商面对的不是简单的最低发电成本问题，而是：

\\[ \min \left( C\_{\mathrm{investment}} +C\_{\mathrm{operation}} +C\_{\mathrm{contract}} +C\_{\mathrm{delay}} \right) \\]

其中，延期损失 \\(C\_{\mathrm{delay}}\\) 是关键。

建设成本较低、但投运较慢的供电方案，未必是开发商的私人最优选择。开发商可能愿意采用成本更高、但更快投运的 RICE、SOFC 或复用机组。

工作包通过技术有效建设周期和真实 COD 来反映速度差异，不需要构建复杂的施工供应链模型。

为保持求解简单，三种供电模式的少量合法转换路径放在 LP 外部枚举，每条路径分别求解连续 LP，再比较结果。不使用 MILP，也不声称枚举结果等于所有可能离散方案的全局最优。

## 四、如何研究长期影响？

仅研究 2035 年以前哪种供电方案最便宜，无法揭示这篇论文真正关心的路径依赖。

因此，工作包采用 2026–2050 年动态分析。

研究时间轴

2026–2035

每年新增 AIDC 需求、投资与扩张决策

2036–2050

新增需求为零，追踪承诺与长期影响

2040/45/50

补充完整扩张求解节点

每年采用五年前瞻规划，但只有当年真正批准的投资和合同会成为不可逆历史承诺；开发商可以看到未来三年已知的具体申请，不能提前知道未来实际发生的所有事件。

随后逐年更新资产状态，记录工程 COD、公共电网扩建、资产退役、项目退出和未交付需求。

这里有两类不同的长期结果：

- 投资路径依赖： 早期为追求快速供电建设的电源，可能降低后续公共扩张需求，也可能在公共电网建成后成为利用率较低的冗余资产。
- 成本与风险分摊： 企业支付的合同费用不一定等于社会真实资源成本；专属资产取消、低利用率和公共补救建设可能改变成本由谁承担。

2036 年后的需求不再增长，PUE 及训练/推理参数保持 2035 年水平，有助于更清楚地观察此前投资决策的长期后果。

## 五、用什么数据和电力系统模型？

工作包采用两张相互连接的模型：

电力系统： PyPSA-USA 负责公共发电、储能、输电及其扩张。

数据中心系统： 自定义轻量级连续 LP 负责已投运 IT 容量、推理任务、训练日内移时、供电选择和未交付需求。

外生数据中心需求

全国 IT 增量（GW）→ 州级分配比例 → PNNL 场址权重 → 电力系统区域

推理负荷

按照 wd/we 的逐时曲线变化，不跨时转移

训练负荷

每日任务量守恒，允许当天移峰

数据中心设施负荷 × 电网物理约束

包含州级 PUE、网络瓶颈、供电资源和储能

地理上先使用 ERCOT 7 区小规模网络，再扩展至美国本土 48 州、约 134 区的全国网络。每个区域必须位于一个州内，但当前真实全国网架是否满足这一点尚待核验。

主规划采用代表性 3 小时时段，关键供电压力使用连续 1 小时片段检查，以控制模型规模。

## 六、最终要从结果中发现什么？

我认为应该围绕以下四个科学发现组织 Nature Energy 论文，而不是按模型功能逐项汇报。

| 核心机制           | 关键科学问题                           | 最值得展示的结果             |
| -------------- | -------------------------------- | -------------------- |
| M1：速度—成本权衡     | 延期损失达到多大时，开发商会选择成本更高但建设更快的 BYOP？ | BYOP 选择边界、速度价值临界点    |
| M2：私人投资—公共扩张反馈 | BYOP 是替代公共投资，还是造成公共和私人资产双重建设？    | 公共装机、输电扩张、BYOP 投资变化  |
| M3：长期路径依赖      | 什么条件下早期快速建设转化为长期闲置、锁定或可再利用资产？    | 资产利用率、搁浅成本、生命周期成本    |
| M4：私人—社会效率偏离   | 开发商私人最优的供电方案在什么条件下偏离社会协调规划？      | S2/S3 真实成本差异、分摊机制临界点 |

这些机制不一定全部表现为 BYOP 的负面影响。

例如，某些区域的 BYOP 可以缓解实际电网瓶颈、避免昂贵的公共建设；另一些区域可能由于缺乏资产再利用能力，产生长期冗余投资。

真正有价值的结论是识别两种结果发生的条件，而不是先假设 BYOP 一定导致系统低效。

## 七、实际实施如何推进？

最新工作包将实施划分为三个阶段。

阶段 1

最小机制原型

合成 LP → ERCOT 7 区 S0/S1 → 引入 BYOP 的 S2 → 社会协调的 S3。首先证明模型能够产生物理合理的供电选择和公共扩张反馈。

阶段 2

长期机制与临界条件

在 ERCOT 上运行多年投资循环，改变 Speed Premium、建设周期、合同价格及资产再利用条件，识别投资路径发生转变的临界点。

阶段 3

全国推广与论文结果

核验全国地理映射，运行 S0–S3，分析不同地区的资源禀赋、输电瓶颈和公共扩张条件如何改变上述机制。

目前工作包已经完成设计规范和部分数据处理及合成 LP 测试，但还没有运行真实的 ERCOT 和全国联合容量扩张模型，因此上述 M1–M4 是待检验的科学假说，而不是已经获得的发现。

## 我对整个顶层设计的评价

目前的研究主线已经比较清晰，而且经过精简后，整体复杂度基本符合“利用模型发现机制，而非精确复现美国电网接入审批”的目标。

但从论文论证角度，我认为有两件事要特别注意：

第一，必须把 M2 和 M3 作为区别于一般 BYOP 技术组合优化研究的核心。 单纯证明燃气、燃料电池或储能能够让数据中心更快投运，难以构成足够强的长期科学贡献。真正需要揭示的是早期私人供电选择怎样重塑后续公共投资，以及这种改变何时产生持久的社会收益或损失。

第二，S2 与 S3 的成本比较必须同时控制实际交付的计算服务。 如果 S3 只是少建设、晚供电，从而得到更低成本，不能据此判断它更有效率。这也是工作包已经要求进行 matched-service 比较的原因。

一句话概括论文主线：

> 数据中心追求更快供电的私人投资行为，并不只是改变新电源由谁建设，而可能改变公共电网未来建设什么、何时建设，以及这些资产在 AI 需求增长结束后是否仍有价值。

我建议下一轮重点讨论的就是 S2 和 S3 的具体决策过程如何形成可比的、真正能够检验这一核心机制的反事实实验。这一点比继续细化设备运行或数据接口更直接决定 Nature Energy 论文的科学说服力。
